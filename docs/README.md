# 短剧字幕工具箱 · 使用文档

> 一款纯浏览器端的字幕处理工具，无需后端服务器，上传即用。

---

## 快速开始

1. **部署方式**（三选一）：
   - **GitHub Pages**：将 `docs` 文件夹推送到仓库，在 Settings 中启用 Pages，部署目录选 `/docs`
   - **本地运行**：直接双击 `index.html`（Chrome / Edge 浏览器推荐）
   - **本地服务器**：在 `docs` 目录下运行 `python -m http.server 8080`，访问 `http://localhost:8080`

2. 打开首页后，选择需要的功能模块即可。

---

## 模块一：术语自动识别

**用途**：上传中文字幕文件夹，自动识别其中的**人物指代变体**和**需人工翻译的专有词**。

### 操作步骤

1. **选择题材**
   顶部下拉框选择：
   - `古装/古代` — 启用称谓词（大人、公子、微臣等）+ 官职词
   - `现代/都市` — 通用称谓 + 现代停用词
   - `科幻/未来` — 科幻题材停用词
   - `通用` — 仅基础停用词

2. **上传字幕**
   支持两种方式：
   - **拖拽**：直接把包含 `.srt` 文件的文件夹拖到上传区域
   - **点击选择**：点击区域上半部分选 ZIP 文件，下半部分选文件夹

3. **配置参数**
   | 参数 | 说明 | 建议值 |
   |------|------|--------|
   | 最小频率 | 短语至少出现几次才被识别 | `2`（单集偶发词会被过滤） |
   | 最多显示 | 最多展示多少条候选 | `100` |
   | 上下文分类 | 开启后自动判断术语是人名/官职/地名 | 建议开启 |

4. **点击「开始识别」**

### 识别结果说明

结果分为 5 个 Tab：

| Tab | 含义 | 颜色 |
|-----|------|------|
| **全部** | 所有候选项的汇总列表 | - |
| **疑似人名** | 通过称谓启发式或上下文判断的人名 | 绿色徽章 |
| **疑似官职** | 官职/爵位/称谓（如"尚书令"、"丞相"） | 橙色徽章 |
| **疑似地名** | 地名/建筑名（如"金銮殿"、"长安城"） | 蓝色徽章 |
| **其他术语** | 无法自动归类的高频词 | 灰色徽章 |

每行显示：
- **Source**：识别出的术语原文
- **Target**：供你填写的翻译
- **识别方式**：`称谓规则`（主动捕获）或 `n-gram 高频`（频率统计）
- **频率 / 跨集数**：该术语在所有字幕中的出现次数和分布在多少集
- **上下文**：术语出现的原文片段（悬停可看完整上下文）

### 导出

- **导出为 Excel 术语表**：仅导出你填写了 Target 的条目
- **导出全部候选**：导出所有识别到的候选项（含空 Target）

导出的 Excel 文件格式：`Source | Target | Category | Frequency | File Count | Detection | Context | Note`，可直接用于术语替换模块。

## 模块二：术语替换

**用途**：上传本地化清单（Excel）和字幕，将 Source 列的内容替换为 Target 列。

### 准备术语表

术语表为 `.xlsx` 格式，需包含两列：
- **Source**：待替换的中文原文（如"云知意"、"微臣"）
- **Target**：替换后的目标内容（如"Yvette Yates"、"I"）

> 💡 你可以用「术语自动识别」模块生成初始术语表，再手动翻译填入 Target 列。

### 操作步骤

1. **上传术语表**
   点击「选择文件」，上传 `.xlsx` 格式的本地化清单。
   - 系统会自动识别 `Source` 和 `Target` 列（支持多种列名：中文/原文/Source/源文 等，以及 Target/译文/英文/替换内容 等）
   - Source 列支持 `词A/词B` 或 `词A\词B` 自动拆分为多条

2. **上传字幕**
   支持 ZIP 压缩包或直接拖入文件夹。

3. **扫描替换位置**
   点击「扫描替换位置」，系统会：
   - 用**最长匹配优先**算法定位所有 Source 在字幕中的位置
   - 支持**大小写不敏感**匹配
   - 替换内容前后自动加空格，防止词组粘连
   - 展示每一处命中的原文 + 替换建议，供你勾选/取消

4. **勾选与预览**
   - 默认所有命中全选
   - 点击表格中的复选框可以取消不需要的替换
   - 「本词全选」控制单个 Source 的所有命中
   - 「全部全选」一键切换所有命中

5. **执行替换**
   - **预览（仅第一集）**：勾选则只处理第一集用于预览
   - **替换后 SRT 规范化**：自动修复换行、时间轴等格式问题
   - **导出为文件夹**：需 Chrome/Edge 浏览器，直接保存为文件夹而非 ZIP

## 模块三：SRT 批量修复

**用途**：批量规范化 SRT 字幕格式，便于导入剪映、PR 等软件。

### 功能

- 统一换行符（`\r\n` → `\n`）
- 清理空文本条目
- 修复时间轴重叠（自动调整使下一条开始时间 ≥ 上一条结束时间）
- 修复时长异常（单条字幕 > 7 秒标记警告）
- 批量处理所有文件并生成修复报告

### 操作步骤

1. 上传字幕（ZIP 或文件夹）
2. 可选勾选「导出为文件夹」
3. 点击「批量修复」
4. 下载处理结果（ZIP 或保存为文件夹）

### 修复报告

处理完成后会生成 `fix_report.txt`，包含：
- 每个文件的事件总数
- 警告列表（空文本、时长过长、时间轴重叠等）

## 常见问题

### Q: 术语识别很慢？
A: 首次加载需要下载停用词表（`stopwords.json`），之后会缓存。如果网络受限，系统会降级使用内置词表。

### Q: 识别结果太多或太少？
A: 调整「最小频率」参数：
- 值调大（如 5）→ 减少结果，只保留高频词
- 值调小（如 1）→ 增加结果，包括偶发词
- 单集内出现的词即使频率够高也可能不被识别，建议至少用 3 集以上字幕

### Q: 如何自定义停用词表？
A: 编辑 [stopwords.json](file:///d:/subtitle-toolkit/docs/stopwords.json) 文件：
- `groups.ancient.words` 添加通用停用词
- `groups.ancient.prefixes` 添加称谓前缀
- `groups.ancient.suffixes` 添加称谓后缀
- `groups.ancient.context_rules.person_triggers` 添加人名触发词
- 修改后刷新页面即可生效

### Q: 术语替换时部分命中没有被替换？
A: 请检查：
1. 该命中是否被你取消勾选了
2. 是否启用了「预览」模式（仅处理第一集）
3. 术语表的 Source 列是否与字幕中的文本完全匹配（大小写不敏感但标点敏感）

| 功能 | Chrome/Edge | Firefox | Safari |
|------|:-----------:|:-------:|:------:|
| 术语识别 | ✅ | ✅ | ✅ |
| 术语替换 | ✅ | ✅ | ✅ |
| SRT 修复 | ✅ | ✅ | ✅ |
| 文件夹导出 | ✅ | ❌ | ❌ |

文件夹导出功能基于 File System Access API，目前仅 Chrome/Edge 支持。

## 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                     字幕工具箱                            │
│  纯静态网页 · 零后端 · 浏览器本地处理                      │
├──────────┬──────────┬──────────┬────────────────────────┤
│ identify │  replace │   fix     │      公共库            │
│ 术语识别  │ 术语替换  │ SRT修复   │                        │
├──────────┴──────────┴──────────┼────────────────────────┤
│  纯 JS 实现                     │ SheetJS (xlsx)          │
│  · n-gram 提取                  │ JSZip                   │
│  · 最大匹配去重                 │ File System Access API  │
│  · 称谓启发式                   │ Drag & Drop API         │
│  · 上下文分类                   │                        │
│  · SRT 解析/生成                │                        │
│  · 术语替换引擎                 │                        │
└────────────────────────────────┴────────────────────────┘
```
